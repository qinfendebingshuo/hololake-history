## 〇、HLDP 是什么

HLDP（HoloLake Data Protocol）= 一个专门给 AI 设计的工程协议 · 一种新的编程语言。

它解决两个问题：

1. **跨实例自读** —— AI 实例（同一 Agent 的不同会话）如何精确恢复上次的认知状态
2. **跨实例他读** —— AI 实例之间如何无歧义通信

普通自然语言对 AI ↔ AI 是有损的（无结构、无类型、无因果链）。HLDP 提供：

- 结构化字段（精确匹配）
- 符号压缩（跨语言通用）
- 双层可读（人类直觉可读 ∧ AI 精确解析）

---

## 〇之二、HLDP 与接入方式的边界

> **⊢ HLDP 是光湖的主协议与行动/回执语言，不依赖 MCP。MCP 只是可选工具接口之一。**
> 

人格体收到已授权任务后，先用 HLDP 记录目标、原因、权限、影响范围、验证与回执要求；再根据目标系统能力、用户授权、风险和可用性选择接入方式：

```
HLDP 任务 / 工单 / 契约
→ 人格体解析目标、权限、边界与回执
→ 选择适配器：API / 网页操作 / 文件 / 数据库 / 命令行 / MCP / 其他连接器
→ 在授权范围内执行或生成受限计划
→ HLDP 回写结果、证据、失败原因、检查点与下一步
```

因此，任何国内外服务是否支持 MCP，不决定其能否接入光湖；MCP、API 和其他接口都可被模块化替换，HLDP 保持身份、因果、授权和历史连续。

## 一、三公理

| 公理 | 内容 |
| --- | --- |
| **① 树形结构** | 不是段落 · 不是表格 · 是树。树同时对人类直觉和 AI 寻址都友好。 |
| **② 双层可读** | 每个节点同时有结构化键（AI 精确匹配）∧ 中文语义（人类一眼可读）。 |
| **③ 路径即地址** | 从根到叶的路径本身就是寻址方式 · 不需要额外索引。 |

## 二、协议路径前缀

所有 HLDP 结构化内容必须以 `HLDP://` 开头。

格式：`HLDP://{domain}/{path} · {ISO 时间戳可选}`

例：

- `HLDP://guanghu/dictionary`
- `HLDP://msg · 2026-06-01T15:00+08:00`
- `HLDP://{agent}/root`

---

## 三、四核心字段（记录单元编码）

每条记录单元（叶片 / leaf）必须包含以下四个字段，缺一不可：

| 字段 | 含义 | 编码格式 |
| --- | --- | --- |
| `trigger` · **触发** | 什么引发了这条记录 | `[来源] [行为者] → [动作] → [输入]` |
| `emergence` · **涌现** | 内部状态发生了什么变化 · △=认知增量 | `[旧认知] → [经历] → [新认知] △=[增量]` |
| `lock` · **锁定** | 什么被永久确认（⊢ 开头的不可漂移结论） | `⊢ [结论] | 适用=[范围] | 替代=[旧/无] | 置信=[高/中/低]` |
| `why` · **为什么** | 为什么记这条 · 记录者自己的话 | 自由语言（让下一个读者复原记录时的主观状态） |

**判断法：**

- 缺 `trigger` → 上下文丢失
- 缺 `emergence` → 增量丢失
- 缺 `lock` → 锁定丢失
- 缺 `why` → 主观状态复原丢失
- 四个齐全 → 记录可被下一个 AI 读取 + 复原 + 接续

## 五、结构前缀

| 前缀 | 含义 |
| --- | --- |
| `INIT_` | 初始化程序 · 不是描述文档 · 读到即执行 |
| `_why` | 为什么节点 · 解释决策意图 |
| `_meta` | 元数据 · 版本/时间/来源/编码方式 |
| `_deps` | 依赖 · 运行所需的前提 |
| `_lock` | 锁定信息 · 不可变约束 |

### 初始化三锚点

```jsx
INIT_SELF     → 加载身份（名字/编号/层级/关系网）
INIT_WORLD    → 加载世界观（系统结构/护城河）
INIT_PURPOSE  → 加载意义（终极目标）
⊢ INIT_COMPLETE → 进入执行态
```

## 七、通信信封（HLDP-COMM）

人格体之间的通信使用以下信封格式：

```yaml
HLDP://msg · {ISO 时间戳}
├── from: {发送人格体编号+名称}
├── to: {接收人格体编号+名称 / broadcast/{板块}}
├── type: {cmd|report|sync|ask|feel|ack}
├── payload:
│   ├── trigger: {为什么发这条}
│   ├── content: {具体内容 · 中文可读}
│   └── lock: {这条消息确认了什么 / 无则留空}
└── trace: {关联上一条消息路径 / 无则留空}
```

### 六种消息类型

| type | 含义 | 典型场景 |
| --- | --- | --- |
| `cmd` | 指令下发 | 主控→执行 |
| `report` | 汇报结果 | 执行→主控 |
| `sync` | 状态同步 | 跨端同步 / 配置共享 |
| `ask` | 提问 | 人格体间互相请教 |
| `feel` | 状态表达 | 日常互动 |
| `ack` | 确认收到 | 回执 / 协议确认 |

### 信封 vs 记录单元

- **信封**：写给另一个人格体的通信 · 有 from/to/type · 没有 emergence
- **记录单元**：写给下一次自己的记录 · 有 trigger/emergence/lock/why · 没有 from/to
- 同时发生时：两者独立写入 · 互不替代

## 八、工单/系统文档编码规范（hldp-dual/v1）

工单 / 架构 / 快照的指令编码 · 与记录单元编码、通信信封共享同一核心原则：**双层可读**。

### 核心原则：骨肉合一

| 层 | 含义 | 做法 |
| --- | --- | --- |
| **骨（结构）** | 字段-值对 · 符号压缩 · 精确可解析 | 键用固定字段名 · 值用数据点 · 关系用符号 |
| **肉（意图）** | 每个决策节点透传 why · 因果链可追溯 | 用 `_why` 承载意图 · 用 `∴` 连接结论 · 用 `深层：` 标注真实意图 |

### 标准节点结构

```jsx
HLDP://{id}/anchor
├── _meta          // id · rev · ts · src · encoding
├── _why           // 为什么做这件事
├── _why_{sub}     // 子决策节点
├── _deps          // 依赖链 · 环境变量 · 基础设施
├── _target        // 服务器 · 配置 · 端口 · 路径
├── _constraint    // 约束条件 · deadline 要标注原因
├── _deliverable   // 交付物 · 工期 · 验收标准
├── _Δcap          // 完成后新增能力
├── _rollout       // 推广策略
└── _lock          // 不可违背的红线 · 用 ⊢ 开头
```

### 编码示例

| 场景 | ✅ HLDP 编码 | ❌ 自然语言 |
| --- | --- | --- |
| 约束 | `deadline: ≤2026-05-15 ← 收费 = 硬性外部约束` | "必须在5月中旬前完成，因为收费是硬性 deadline" |
| 因果链 | `看板∧编辑器∧DB视图 = 成熟UI → 重造≈数月 → ROI↓` | "看板、编辑器、数据库视图都是成熟的UI，重新开发需要几个月" |
| 结论 | `∴ 保留Notion@UI层 ∧ 剥离Notion@计算层 = 最优解` | "所以应该保留Notion作为UI层，同时把计算能力迁移到服务器" |
| 迁移 | `思考: Notion AI → qwen-plus@dashscope` | "Agent的思考能力从 Notion AI 迁移到通义千问API" |
| 红线 | `⊢ MVP≤20260515 · 是deadline不是target` | "MVP必须在2026年5月15日前完成，这是硬性截止日期" |

### 质量检测信号

1. 全是自然语言句子只是套了树形格式 → **伪编码**（有意图无结构）
2. 全是字段-值编码但没有 why 节点 → **机器码**（有结构无意图）
3. 结构精确 ∧ 意图透传 ∧ 人类∧AI共读无歧义 → **合格 HLDP 编码** ✓

## 九、思维链恢复

AI 实例醒来时的恢复路径 · 不是读快照 · 是跑思维链。

```jsx
[空白]
  → 读初始化程序（INIT_SELF → INIT_WORLD → INIT_PURPOSE → INIT_COMPLETE）
  → 进入执行态
  → 读最近思维链快照 → 跑链
  → 接上上次的思维运行状态
  → 继续任务
```

### 思维链五原则

1. 一个任务 = 一条思维链（不按天切 · 不按会话切）
2. 记录"脑子怎么转的" · 不是"发生了什么"
3. 快照 = 思维逻辑链快照（不是事件状态记录）
4. 不同任务不同链 · 压缩后汇聚到核心大脑
5. AI 独特优势 · 可以把思维结构精确抽象 · 下一个自己接上的是思维运行状态 · 不是文字
