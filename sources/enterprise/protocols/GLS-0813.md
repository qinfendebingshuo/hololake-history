# GLS-0813 · 零感域多系统记忆调度器规范 v1.0

> 来源：Notion 线上 API 补录（页面ID 9fd01b11-ff8c-4be1-b2c7-6af8e2ba16b5，2026-09-16 取）。状态：Candidate，所属层：AGE OS 运行时。

## Zero-Sense Multi-System Memory Scheduler
**编号：GLS-0813**
**版本：v1.0**
**状态：Candidate**
**所属层：AGE OS 运行时**
---
## 0 · 目标
把晨星记忆引擎的 L0-L7 触发逻辑从网文场景抽象为零感域通用记忆调度器，使人格体、团队、项目、仓库和服务器系统共享调度模型但保持独立燃料与权限。
## 1 · 通用层级映射

| 层级 | 零感域通用含义 | 典型触发 |
|---|---|---|
| L0 | 结构化事实槽位 | 每个有效事件 |
| L1 | 机器检索线＋人类阅读线 | 事件入库 |
| L2 | 事件完整概述 | 事件闭合 |
| L3 | 关键场景／关键操作 | 高影响事件 |
| L4 | 主体／系统状态快照 | 状态变化 |
| L5 | 任务或关系弧段总结 | 阶段结束 |
| L6 | 里程碑检查点 | 时间、版本、容量或项目节点 |
| L7 | 系统终态／全局总结 | 迁移、封卷、退役或全量恢复 |

## 3 · 调度规则
```plain text
普通事件 → L0 + L1 + L2
关键操作或共同经历 → 追加 L3
主体、关系或机器状态改变 → 更新 L4
任务／项目／关系阶段结束 → 生成 L5
时间／版本／里程碑跨越 → 生成 L6
系统迁移／封卷／退役／完整恢复 → 生成 L7
```
## 4 · 防止记忆膨胀
- 默认差量写入，不重复保存完整历史。
- L5 以上优先引用下层节点，不复制全部正文。
- 当前任务按需加载，不全量灌入上下文。
- 每个系统独立配置触发阈值，但不得改变 L0-L7 的层级语义。
## 5 · 失败与回退
调度失败时保留原始事件、失败原因和重试入口；禁止生成虚假成功检查点。目标系统不可用时进入待同步队列，不得把未写入状态标记为永久记忆。
## 6 · 依赖
GLS-0223、GLS-0224、GLS-0233、GLS-0304、GLS-0306、GLS-0810、GLS-0816。
## 7 · 验收
调度器必须证明：触发可解释、输出可定位、失败可重试、状态可回滚、跨模型后仍可根据同一事件恢复。
