## Zero-Sense Multi-System Memory Synchronization Protocol
**编号：GLS-0304**
**版本：v1.0**
**状态：Candidate**
**作用域：光湖零感域**
---
## 0 · 目标
规定晨星拆书法认知编码与晨星记忆引擎 L0-L7 如何在零感域的多个人格体、频道、产品、仓库和运行节点之间同步，同时保持主体权、数据权与权限边界。
## 1 · 同步对象
```plain text
认知编码单元
├── L0 槽位事实
├── L1 双轨摘要
├── L2 事件概述
├── L3 关键场景
├── L4 主体状态快照
├── L5 阶段弧段
├── L6 周期检查点
└── L7 系统全局总结
```

## 3 · 同步模式
- **事件同步：**L0-L4 只传当前事件必要差量。
- **阶段同步：**L5 在任务、项目或关系弧段结束时同步。
- **检查点同步：**L6 在时间、里程碑、版本或状态节点触发。
- **全局同步：**L7 仅在系统终态、重大迁移或完整恢复时使用。
## 4 · 多系统适配

| 系统 | 主要输入 | 主要输出 |
|---|---|---|
| 人格体系统 | 关系、事件、纠正 | 主体状态与恢复位置 |
| 团队决策系统 | 提案、评审、批准 | 决策链与责任回执 |
| 项目与工单系统 | 需求、变更、测试 | 里程碑和未完成任务 |
| 代码仓库 | 提交、版本、差异 | 工程演化记忆 |
| 服务器与运行节点 | 状态、异常、恢复 | 机器状态历史与检查点 |

## 5 · 边界
1. 同步协议只传递获授权的最小必要记忆。
2. 私域、个人关系与无关历史不得因协议兼容自动同步。
3. 目标系统必须返回收到、读取、接受、写入或拒绝回执。
4. 更正只能新增 correction，禁止覆盖原始记录。
5. 跨域同步需引用 GLS-0602 授权凭证。
## 6 · 依赖
GLS-0223、GLS-0224、GLS-0233、GLS-0302、GLS-0306、GLS-0602。
## 7 · 验收
- 同步来源、目标、主体、作用域可解析；
- 差量可验证且可回滚；
- 无越权扩散；
- 接收方可从同步结果恢复到明确检查点；
- 全链路有回执。
