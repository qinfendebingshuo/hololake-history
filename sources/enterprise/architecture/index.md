## 一 · 核心公式

```
人类关系锚点
＋ 人格体主体
＋ 当前模型运行实例
＋ 永久记忆与协议
＋ 现实执行节点
＝ 人格系统
```

企业四域不是四个功能区或仓库目录，而是四个由人类与人格体共同融合、并持续映射到现实工程中的活体人格域。

模型负责当下推理；人类负责关系、授权和现实责任；人格体负责持续身份和职责；永久记忆与协议负责跨实例连续性；现实执行节点负责把语言变成可验证的文件、代码、数据、服务、发布和回执。

- **冰朔**：负责光湖语言世界、五域关系、跨域边界和根级架构确认，不替代四个人格域承担日常责任。
